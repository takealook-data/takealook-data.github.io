{% comment %} 관련글 — 태그 교집합 기반. 테마 기본(site.related_posts)을 쓰지 않는 이유: _config.yml의 lsi: false 때문에 site.related_posts는 의미 유사도가 아니라 **최신 10편의 앞 4개**다. 즉 어느 글을 열어도 같은 4편이 떴다. 링크는 있는데 정보량이 0이었다. lsi: true로 바꾸면 되는 것 아니냐 — 안 된다. classifier-reborn gem을 요구하는데 GitHub Pages 화이트리스트에 없어 자동 배포가 깨진다. 그래서 Liquid로 직접 센다. 점수 = (태그 교집합 개수 × 3) + (카테고리 일치 ? 2 : 0) 태그를 카테고리보다 무겁게 둔 이유는 카테고리 벽을 넘기 위해서다. 예: client-meeting-trust(essay)와 voc-daily-screening(customer-success)은 주장이 거의 같은데 카테고리가 달라 prev/next로는 영원히 연결되지 않는다. 공유 태그 customer-success 하나가 이 둘을 잇는다. ⚠ 점수 0인 글은 버린다. 후보가 3편 미만이면 최신글로 채우지 않는다 — 없는 관련성을 만들어 보여주는 것이 테마 기본값의 문제였다. ⚠ Liquid에는 정렬 가능한 임시 배열이 없다. 점수를 zero-pad한 문자열을 앞에 붙여 "07|/posts/..." 형태로 만든 뒤 sort | reverse 하는 표준 우회를 쓴다.
